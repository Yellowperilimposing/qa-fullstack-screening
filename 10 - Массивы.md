## 10. Массивы

> [!abstract] Коротко
> Массив — это структура данных, которая хранит несколько значений одного типа.


### 10.1. Что такое массив

**Массив** — это структура данных, которая хранит несколько значений одного типа.

Например, несколько чисел:

```java
int[] numbers = {10, 20, 30};
```

Массив можно представить как список:

```text
Индекс:    0   1   2
Значение: 10  20  30
```

Важно: индексы в Java начинаются с `0`.

---

### 10.2. Объявление массива

Есть несколько вариантов объявления массива.

Рекомендуемый вариант:

```java
int[] numbers;
```

Также можно так, но это менее распространённый стиль:

```java
int numbers[];
```

Примеры массивов разных типов:

```java
int[] ages;
String[] names;
boolean[] results;
double[] prices;
```

---

### 10.3. Инициализация массива сразу со значениями

```java
int[] numbers = {1, 2, 3, 4, 5};
```

```java
String[] names = {"Danil", "Ivan", "Oleg"};
```

```java
boolean[] checks = {true, false, true};
```

---

### 10.4. Создание массива через new

```java
int[] numbers = new int[5];
```

Это массив на 5 элементов.

По умолчанию значения будут такими:

```text
[0, 0, 0, 0, 0]
```

Для разных типов значения по умолчанию разные:

| Тип массива      | Значение по умолчанию |
| ---------------- | --------------------- |
| `int[]`          | `0`                   |
| `double[]`       | `0.0`                 |
| `boolean[]`      | `false`               |
| `String[]`       | `null`                |
| объектный массив | `null`                |

Пример:

```java
String[] names = new String[3];

System.out.println(names[0]); // null
```

---

### 10.5. Заполнение массива

```java
int[] numbers = new int[3];

numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;
```

---

### 10.6. Получение элемента массива

```java
int[] numbers = {10, 20, 30};

System.out.println(numbers[0]); // 10
System.out.println(numbers[1]); // 20
System.out.println(numbers[2]); // 30
```

---

### 10.7. Длина массива

Для получения длины используется `.length`.

```java
int[] numbers = {10, 20, 30};

System.out.println(numbers.length); // 3
```

---

### 10.8. Перебор массива через for

```java
int[] numbers = {10, 20, 30};

for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}
```

Этот вариант удобен, когда нужен индекс элемента.

---

### 10.9. Перебор массива через for-each

```java
int[] numbers = {10, 20, 30};

for (int number : numbers) {
    System.out.println(number);
}
```

Этот вариант удобен, когда нужно просто пройтись по всем значениям.

---

### 10.10. Частая ошибка с массивами

```java
int[] numbers = {10, 20, 30};

System.out.println(numbers[3]);
```

Будет ошибка:

```text
ArrayIndexOutOfBoundsException
```

Почему?

Потому что в массиве 3 элемента, но индексы такие:

```text
0, 1, 2
```

Индекса `3` нет.
