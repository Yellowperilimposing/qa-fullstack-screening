## 16. Работа со строками

> [!abstract] Коротко
> String — это класс для работы со строками.


### 16.1. Что такое String

`String` — это класс для работы со строками.

```java
String name = "Danil";
```

Важно: `String` — это ссылочный тип, а не примитив.

---

### 16.2. Строки неизменяемые

`String` в Java является immutable, то есть неизменяемым.

Пример:

```java
String text = "Hello";
text = text + " Java";

System.out.println(text); // Hello Java
```

Кажется, что строка изменилась, но на самом деле создался новый объект строки.

---

### 16.3. Конкатенация строк

**Конкатенация** — соединение строк.

```java
String firstName = "Danil";
String lastName = "Ivanov";

String fullName = firstName + " " + lastName;

System.out.println(fullName);
```

Можно соединять строку и число:

```java
int age = 28;

String text = "Возраст: " + age;

System.out.println(text); // Возраст: 28
```

---

### 16.4. Основные методы String

#### length()

Возвращает длину строки.

```java
String text = "Java";

System.out.println(text.length()); // 4
```

---

#### toUpperCase()

Переводит строку в верхний регистр.

```java
String text = "java";

System.out.println(text.toUpperCase()); // JAVA
```

---

#### toLowerCase()

Переводит строку в нижний регистр.

```java
String text = "JAVA";

System.out.println(text.toLowerCase()); // java
```

---

#### contains()

Проверяет, содержит ли строка другую строку.

```java
String text = "I learn Java";

System.out.println(text.contains("Java")); // true
```

---

#### startsWith()

Проверяет, начинается ли строка с указанного значения.

```java
String text = "Java developer";

System.out.println(text.startsWith("Java")); // true
```

---

#### endsWith()

Проверяет, заканчивается ли строка указанным значением.

```java
String fileName = "report.pdf";

System.out.println(fileName.endsWith(".pdf")); // true
```

---

#### substring()

Возвращает часть строки.

```java
String text = "Hello Java";

System.out.println(text.substring(0, 5)); // Hello
```

Важно:

```java
substring(0, 5)
```

берёт символы с индекса `0` до индекса `5`, но индекс `5` не включается.

---

#### replace()

Заменяет часть строки.

```java
String text = "Hello Java";

System.out.println(text.replace("Java", "World")); // Hello World
```

---

#### trim()

Удаляет пробелы в начале и конце строки.

```java
String text = "  Java  ";

System.out.println(text.trim()); // Java
```

---

#### isEmpty()

Проверяет, пустая ли строка.

```java
String text = "";

System.out.println(text.isEmpty()); // true
```

---

#### isBlank()

Проверяет, пустая строка или состоит только из пробелов.

```java
String text = "   ";

System.out.println(text.isBlank()); // true
```

---

### 16.5. Сравнение строк

Строки нельзя правильно сравнивать через `==`, если нужно сравнить текст.

Неправильно:

```java
String a = new String("Java");
String b = new String("Java");

System.out.println(a == b); // false
```

Почему `false`?

Потому что `==` сравнивает ссылки, то есть проверяет, один и тот же это объект или нет.

Правильно:

```java
String a = new String("Java");
String b = new String("Java");

System.out.println(a.equals(b)); // true
```

---

### 16.6. `equals()` и `==`

`==` и `equals()` отвечают на разные вопросы.

| Проверка | Что сравнивает |
| --- | --- |
| `==` | Ссылки: один и тот же объект или нет |
| `equals()` | Содержимое объекта, если метод правильно реализован |

Пример:

```java
String a = new String("Java");
String b = new String("Java");

System.out.println(a == b);      // false
System.out.println(a.equals(b)); // true
```

`a == b` возвращает `false`, потому что это два разных объекта в памяти.

`a.equals(b)` возвращает `true`, потому что текст внутри одинаковый.

---

### 16.7. Для чего может понадобиться сравнение ссылок через `==`

Сравнение через `==` может понадобиться, когда важно проверить, что две переменные указывают на один и тот же объект.

Пример:

```java
User user = new User("Danil");

User first = user;
User second = user;

System.out.println(first == second); // true
```

Это значит, что `first` и `second` ссылаются на один объект.

`==` также используют для:

* сравнения примитивов;
* проверки на `null`;
* сравнения enum-значений;
* проверки, что два объекта — это один и тот же экземпляр.

Пример проверки на `null`:

```java
if (user == null) {
    System.out.println("Объекта нет");
}
```

Пример с enum:

```java
if (status == Status.ACTIVE) {
    System.out.println("Активен");
}
```

---

### 16.8. equalsIgnoreCase()

Сравнивает строки без учёта регистра.

```java
String a = "java";
String b = "JAVA";

System.out.println(a.equalsIgnoreCase(b)); // true
```

---

### 16.9. Безопасное сравнение с null

Плохо:

```java
String status = null;

System.out.println(status.equals("ACTIVE")); // NullPointerException
```

Хорошо:

```java
String status = null;

System.out.println("ACTIVE".equals(status)); // false
```

Так программа не упадёт, даже если `status` равен `null`.
