## 16. Работа со строками

> [!abstract] Коротко
> `String` — неизменяемый ссылочный тип. Для частых изменений строки обычно используют `StringBuilder`.

### 16.1. `String`

```java
String name = "Danil";
```

`String` — класс, не примитив. Объекты `String` immutable: методы и операции не меняют существующую строку, а создают результат.

```java
String text = "Hello";
text = text + " Java"; // ссылка text теперь указывает на другую строку
```

---

### 16.2. Строковый пул

Строковые литералы могут переиспользоваться JVM через string pool:

```java
String a = "Java";
String b = "Java";
System.out.println(a == b); // часто true из-за пула
```

Но полагаться на `==` для сравнения текста нельзя:

```java
String a = new String("Java");
String b = new String("Java");

System.out.println(a == b);      // false
System.out.println(a.equals(b)); // true
```

`==` для ссылок проверяет идентичность объектов, `equals()` у `String` — содержимое.

---

### 16.3. Основные методы

```java
String text = "  Hello Java  ";

text.length();
text.contains("Java");
text.startsWith("Hello");
text.endsWith("Java");
text.substring(2, 7);
text.replace("Java", "World");
text.toUpperCase();
text.toLowerCase();
text.trim();
text.strip();
text.isEmpty();
text.isBlank();
```

`substring(begin, end)` включает `begin`, но не включает `end`.

`trim()` исторически ориентирован на символы с кодом до U+0020, а `strip()` использует Unicode-aware определение пробельных символов и обычно предпочтительнее для современного кода.

---

### 16.4. Null-safe сравнение

```java
String status = null;

boolean active = "ACTIVE".equals(status); // false, без NPE
```

Также можно использовать:

```java
Objects.equals(first, second);
```

для null-safe сравнения двух ссылок.

---

### 16.5. `StringBuilder`

При множественных изменениях строки конкатенация в цикле может создавать много промежуточных объектов. Для такого сценария используют `StringBuilder`:

```java
StringBuilder builder = new StringBuilder();

for (int i = 0; i < 3; i++) {
    builder.append(i).append(' ');
}

String result = builder.toString();
```

Полезные методы:

```java
builder.append("text");
builder.insert(0, "prefix");
builder.delete(0, 2);
builder.replace(0, 3, "new");
builder.reverse();
```

`StringBuilder` изменяемый и не синхронизированный. `StringBuffer` похож, но его методы синхронизированы и обычно имеют лишние накладные расходы, если потокобезопасность не нужна.

---

### 16.6. Конкатенация

Для небольших выражений `+` остаётся нормальным и читаемым:

```java
String message = "Hello, " + name;
```

`StringBuilder` нужен не «всегда», а прежде всего при динамическом многократном построении строки.

---

### 16.7. Unicode и `length()`

`String.length()` возвращает количество UTF-16 code units, а не обязательно число видимых Unicode-символов.

Для символов вне BMP один code point может занимать два `char`. Если задача зависит именно от Unicode code points, используют методы вроде `codePointCount()`.
