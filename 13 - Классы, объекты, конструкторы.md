## 13. Классы, объекты, конструкторы

> [!abstract] Коротко
> Класс — это шаблон для создания объектов.


### 13.1. Что такое класс

**Класс** — это шаблон для создания объектов.

Например, класс `User` описывает, какие данные и действия есть у пользователя.

```java
public class User {
    String name;
    int age;
}
```

---

### 13.2. Что такое объект

**Объект** — это конкретный экземпляр класса.

Если класс — это чертёж, то объект — это созданная по нему вещь.

```java
User user = new User();
```

Здесь `user` — объект класса `User`.

---

### 13.3. Поля класса

**Поля** — это переменные внутри класса.

Они описывают состояние объекта.

```java
public class User {
    String name;
    int age;
    String email;
}
```

---

### 13.4. Методы класса

**Методы** — это действия, которые может выполнять объект.

```java
public class User {
    String name;

    public void sayHello() {
        System.out.println("Привет, меня зовут " + name);
    }
}
```

---

### 13.5. Создание объекта и обращение к полям

```java
public class Main {
    public static void main(String[] args) {
        User user = new User();

        user.name = "Danil";
        user.age = 28;

        System.out.println(user.name);
        System.out.println(user.age);
    }
}
```

---

### 13.6. Конструктор

**Конструктор** — это специальный метод, который вызывается при создании объекта.

Особенности конструктора:

* называется так же, как класс;
* не имеет возвращаемого типа;
* используется для начальной настройки объекта.

```java
public class User {
    String name;
    int age;

    public User(String userName, int userAge) {
        name = userName;
        age = userAge;
    }
}
```

Создание объекта:

```java
User user = new User("Danil", 28);
```

---

### 13.7. Конструктор без параметров

```java
public class User {
    String name;
    int age;

    public User() {
        name = "Unknown";
        age = 0;
    }
}
```

Использование:

```java
User user = new User();

System.out.println(user.name); // Unknown
```

---

### 13.8. Несколько конструкторов

В классе может быть несколько конструкторов.

```java
public class User {
    String name;
    int age;

    public User() {
        name = "Unknown";
        age = 0;
    }

    public User(String userName) {
        name = userName;
        age = 0;
    }

    public User(String userName, int userAge) {
        name = userName;
        age = userAge;
    }
}
```

Использование:

```java
User user1 = new User();
User user2 = new User("Danil");
User user3 = new User("Danil", 28);
```

Это называется **перегрузка конструкторов**.
