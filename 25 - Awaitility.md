## 25. Awaitility

> [!abstract] Коротко
> Awaitility — Java-библиотека для умных ожиданий в автотестах.


**Awaitility** — Java-библиотека для умных ожиданий в автотестах.

Она нужна, когда результат появляется не сразу:

* API обрабатывает запрос асинхронно;
* статус меняется через несколько секунд;
* сообщение приходит в очередь;
* данные появляются в базе не мгновенно;
* событие происходит с задержкой.

Awaitility позволяет ждать условие, а не ставить жесткую паузу через `Thread.sleep()`.

---

### 25.1. Зачем нужна Awaitility

Плохой вариант:

```java
Thread.sleep(5000);

assertThat(order.getStatus()).isEqualTo("PAID");
```

Почему плохо:

* тест всегда ждет 5 секунд, даже если результат появился быстрее;
* если результат появился через 6 секунд, тест упадет;
* такие тесты становятся медленными и нестабильными.

Лучше использовать Awaitility:

```java
await()
        .atMost(10, SECONDS)
        .untilAsserted(() -> {
            assertThat(order.getStatus()).isEqualTo("PAID");
        });
```

---

### 25.2. Как работает Awaitility

Awaitility делает повторные проверки до тех пор, пока:

* условие не выполнится;
* не закончится максимальное время ожидания.

Если условие выполнилось раньше, тест сразу идет дальше.

Если условие не выполнилось за отведенное время, тест падает.

---

### 25.3. Основные методы

| Метод | Для чего нужен |
| --- | --- |
| `await()` | Начинает ожидание |
| `atMost()` | Максимальное время ожидания |
| `atLeast()` | Минимальное время ожидания |
| `pollInterval()` | Как часто проверять условие |
| `until()` | Ждать, пока условие станет `true` |
| `untilAsserted()` | Повторять assertion, пока он не пройдет |
| `ignoreExceptions()` | Игнорировать исключения во время ожидания |

---

### 25.4. Пример с условием

```java
await()
        .atMost(10, SECONDS)
        .until(() -> orderService.isPaid(orderId));
```

Здесь тест ждет максимум 10 секунд, пока заказ не станет оплаченным.

---

### 25.5. Пример с AssertJ

```java
await()
        .atMost(10, SECONDS)
        .pollInterval(1, SECONDS)
        .untilAsserted(() -> {
            Order order = orderService.getOrder(orderId);

            assertThat(order.getStatus()).isEqualTo("PAID");
        });
```

Здесь Awaitility каждую секунду получает заказ и проверяет статус.

---

### 25.6. Когда использовать Awaitility

Awaitility хорошо подходит для:

* API-тестов;
* интеграционных тестов;
* тестов с очередями;
* тестов с асинхронной обработкой;
* проверок, где результат появляется не сразу.

Для UI-тестов на Selenide часто достаточно встроенных ожиданий Selenide: `shouldBe`, `shouldHave`.

---

### 25.7. Что важно сказать на скрининге

Awaitility — библиотека для ожидания условий в Java-тестах. Она помогает не использовать `Thread.sleep()`, а ждать конкретный результат: изменение статуса, появление данных или выполнение assertion.
