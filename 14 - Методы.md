## 14. Методы

> [!abstract] Коротко
> Метод — это блок кода, который выполняет конкретное действие.


### 14.1. Что такое метод

**Метод** — это блок кода, который выполняет конкретное действие.

Методы нужны, чтобы:

* не дублировать код;
* разделять программу на логические части;
* переиспользовать код;
* делать программу понятнее.

Пример метода:

```java
public void printHello() {
    System.out.println("Привет");
}
```

---

### 14.2. Сигнатура метода

**Сигнатура метода** — это имя метода и список его параметров.

Пример:

```java
public int sum(int a, int b) {
    return a + b;
}
```

Сигнатура метода:

```java
sum(int a, int b)
```

Важно: возвращаемый тип не входит в сигнатуру метода.

---

### 14.3. Общая структура метода

```java
модификаторДоступа типВозврата имяМетода(параметры) {
    // тело метода
}
```

Пример:

```java
public int sum(int a, int b) {
    return a + b;
}
```

Разбор:

| Часть           | Значение                   |
| --------------- | -------------------------- |
| `public`        | модификатор доступа        |
| `int`           | тип возвращаемого значения |
| `sum`           | имя метода                 |
| `int a, int b`  | параметры                  |
| `return a + b;` | возвращаемое значение      |

---

### 14.4. Метод без параметров и без возвращаемого значения

```java
public void printHello() {
    System.out.println("Привет");
}
```

Вызов:

```java
printHello();
```

`void` означает, что метод ничего не возвращает.

---

### 14.5. Метод с параметрами

```java
public void greet(String name) {
    System.out.println("Привет, " + name);
}
```

Вызов:

```java
greet("Danil");
```

Результат:

```text
Привет, Danil
```

---

### 14.6. Метод с возвращаемым значением

```java
public int sum(int a, int b) {
    return a + b;
}
```

Вызов:

```java
int result = sum(5, 3);

System.out.println(result); // 8
```

---

### 14.7. Локальные переменные в методе

**Локальная переменная** — это переменная, объявленная внутри метода.

```java
public void printUserInfo() {
    String name = "Danil";
    int age = 28;

    System.out.println(name);
    System.out.println(age);
}
```

Локальные переменные доступны только внутри метода, где они объявлены.

---

### 14.8. Вызов метода у объекта

```java
public class User {
    public void sayHello() {
        System.out.println("Привет");
    }
}
```

```java
User user = new User();

user.sayHello();
```

---

### 14.9. Статический метод

**Статический метод** принадлежит классу, а не объекту.

```java
public class MathUtils {
    public static int square(int number) {
        return number * number;
    }
}
```

Вызов:

```java
int result = MathUtils.square(5);

System.out.println(result); // 25
```

Объект создавать не нужно.

---

### 14.10. Перегрузка методов

**Перегрузка методов** — это несколько методов с одинаковым именем, но разными параметрами.

```java
public class Calculator {
    public int sum(int a, int b) {
        return a + b;
    }

    public int sum(int a, int b, int c) {
        return a + b + c;
    }

    public double sum(double a, double b) {
        return a + b;
    }
}
```

Вызов:

```java
Calculator calculator = new Calculator();

calculator.sum(1, 2);
calculator.sum(1, 2, 3);
calculator.sum(1.5, 2.5);
```
