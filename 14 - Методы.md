## 14. Методы

> [!abstract] Коротко
> Метод — именованный блок кода с параметрами и, при необходимости, возвращаемым значением.

### 14.1. Структура метода

```java
public int sum(int a, int b) {
    return a + b;
}
```

Здесь `public` — модификатор доступа, `int` — возвращаемый тип, `sum` — имя, `int a, int b` — параметры.

`void` означает отсутствие возвращаемого значения.

---

### 14.2. Сигнатура метода

При перегрузке Java различает методы по имени и типам/порядку параметров.

```java
sum(int, int)
sum(double, double)
```

Возвращаемый тип сам по себе не позволяет перегрузить метод:

```java
int value() { return 1; }
// double value() { return 1.0; } // ошибка: та же сигнатура
```

Имена параметров (`a`, `b`) не являются частью сигнатуры для выбора перегрузки.

---

### 14.3. Параметры и аргументы

Параметры объявляются в методе, аргументы передаются при вызове:

```java
void greet(String name) { // name — параметр
    System.out.println(name);
}

greet("Danil"); // "Danil" — аргумент
```

Java всегда передаёт аргументы **по значению**. Для объекта копируется значение ссылки, а не сам объект.

```java
void rename(User user) {
    user.setName("Anna"); // меняет состояние того же объекта
    user = new User();     // не меняет ссылку у вызывающего кода
}
```

---

### 14.4. `return`

Метод с ненулевым возвращаемым типом должен вернуть совместимое значение на всех достижимых путях:

```java
int max(int a, int b) {
    return a > b ? a : b;
}
```

В `void`-методе можно использовать пустой `return;` для досрочного выхода.

---

### 14.5. Перегрузка

```java
int sum(int a, int b) { return a + b; }
int sum(int a, int b, int c) { return a + b + c; }
double sum(double a, double b) { return a + b; }
```

Перегрузка выбирается на этапе компиляции по набору аргументов.

---

### 14.6. Varargs

Последний параметр метода может принимать переменное число аргументов:

```java
int sum(int... numbers) {
    int result = 0;
    for (int number : numbers) {
        result += number;
    }
    return result;
}
```

Внутри метода `numbers` — обычный массив `int[]`.

---

### 14.7. `static`

Статический метод принадлежит классу:

```java
class MathUtils {
    static int square(int value) {
        return value * value;
    }
}

int result = MathUtils.square(5);
```

Статический метод не имеет `this` и не может напрямую обращаться к нестатическим полям без объекта.

---

### 14.8. Локальные переменные и область видимости

Локальная переменная существует только в своём блоке и должна быть инициализирована до чтения:

```java
void print() {
    int value = 10;
    System.out.println(value);
}
```
