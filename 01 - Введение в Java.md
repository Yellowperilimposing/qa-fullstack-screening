### 1.1. Что такое Java?

**Java** — это язык программирования, на котором пишут:

* backend-сервисы;
* Android-приложения;
* автотесты;
* корпоративные системы;
* микросервисы;
* веб-приложения.

Главная идея Java: **написал один раз — запускай где угодно**.

Это возможно благодаря тому, что Java-программа не запускается напрямую операционной системой. Сначала она компилируется в специальный промежуточный код — **bytecode**, а затем выполняется внутри **JVM**.

Пример простой Java-программы:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

Эта программа выводит в консоль:

```text
Hello, Java!
```

### 1.2. JVM, JRE, JDK

В Java часто встречаются три важных понятия:

| Термин | Расшифровка              | Для чего нужен                     |
| ------ | ------------------------ | ---------------------------------- |
| JVM    | Java Virtual Machine     | Запускает Java-программы           |
| JRE    | Java Runtime Environment | Среда для запуска Java-программ    |
| JDK    | Java Development Kit     | Набор для разработки Java-программ |

#### JVM

**JVM** — это виртуальная машина Java.

Она выполняет Java bytecode.

Простыми словами:

```text
Java-код → bytecode → JVM → программа работает
```

JVM позволяет запускать одну и ту же Java-программу на разных операционных системах: Windows, macOS, Linux.

---

#### JRE

**JRE** — это среда выполнения Java.

Она нужна, чтобы **запускать** Java-программы.

В JRE входит:

* JVM;
* стандартные библиотеки Java.

Если ты только запускаешь Java-приложение, тебе достаточно JRE.

---

#### JDK

**JDK** — это набор разработчика Java.

Он нужен, чтобы **писать, компилировать и запускать** Java-программы.

В JDK входит:

* JRE;
* компилятор `javac`;
* инструменты для разработки.

Если ты хочешь разрабатывать на Java, тебе нужен именно **JDK**.

### 1.3. Структура Java-программы

Пример:

```java
public class Main {

    public static void main(String[] args) {
        System.out.println("Привет!");
    }

}
```

Разберём по частям.

```java
public class Main
```

Это объявление класса. В Java почти весь код находится внутри классов.

```java
public static void main(String[] args)
```

Это главный метод программы. Именно с него начинается выполнение обычной Java-программы.

```java
System.out.println("Привет!");
```

Эта команда выводит текст в консоль.

Общая структура:

```java
public class ИмяКласса {

    public static void main(String[] args) {
        // код программы
    }

}
```

Важно:

* имя файла обычно должно совпадать с именем public-класса;
* если класс называется `Main`, файл должен называться `Main.java`;
* Java чувствительна к регистру: `Main`, `main` и `MAIN` — разные имена.
