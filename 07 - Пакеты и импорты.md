## 7. Пакеты и импорты

> [!abstract] Коротко
> Пакет — это способ группировать классы.


### 7.1. Что такое пакет?

**Пакет** — это способ группировать классы.

Пакеты помогают:

* структурировать проект;
* избегать конфликтов имён;
* быстрее находить нужные классы.

Пример объявления пакета:

```java
package ru.company.project;
```

Обычно эта строка находится в самом начале файла.

Пример структуры проекта:

```text
src
└── main
    └── java
        └── ru
            └── company
                └── project
                    └── User.java
```

В файле `User.java` будет:

```java
package ru.company.project;

public class User {
}
```

---

### 7.2. Зачем нужны пакеты?

Допустим, в проекте много классов:

```text
User
Order
Payment
Product
TestData
ApiClient
```

Если все классы лежат в одном месте, проект быстро становится неудобным.

Лучше разделить их по пакетам:

```text
ru.company.project.users
ru.company.project.orders
ru.company.project.payments
ru.company.project.tests
```

---

### 7.3. Импорт классов

Если нужно использовать класс из другого пакета, его нужно импортировать.

Пример:

```java
import java.util.ArrayList;
```

Полный пример:

```java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<String> names = new ArrayList<>();
    }
}
```

Без импорта пришлось бы писать полное имя класса:

```java
java.util.ArrayList<String> names = new java.util.ArrayList<>();
```

---

### 7.4. Импорт всех классов из пакета

Можно импортировать все классы из пакета через `*`.

```java
import java.util.*;
```

Но чаще лучше импортировать конкретные классы:

```java
import java.util.ArrayList;
import java.util.List;
```

Так код понятнее.

---

### 7.5. java.lang импортируется автоматически

Классы из пакета `java.lang` импортируются автоматически.

Например, не нужно импортировать:

```java
String
System
Math
Integer
Double
```

Можно сразу писать:

```java
String text = "Java";
System.out.println(text);
```
