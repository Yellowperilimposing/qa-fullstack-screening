## 15. Модификаторы доступа и пакетная структура

> [!abstract] Коротко
> Модификаторы доступа определяют, откуда можно обращаться к классу, полю, методу или конструктору.


### 15.1. Что такое модификаторы доступа

**Модификаторы доступа** определяют, откуда можно обращаться к классу, полю, методу или конструктору.

Основные модификаторы:

1. `public`;
2. `protected`;
3. default, то есть без модификатора;
4. `private`.

---

### 15.2. public

`public` — доступ отовсюду.

```java
public class User {
    public String name;

    public void sayHello() {
        System.out.println("Привет");
    }
}
```

Используется, когда класс или метод должен быть доступен из других частей программы.

Пример:

```java
user.sayHello();
```

---

### 15.3. private

`private` — доступ только внутри текущего класса.

```java
public class User {
    private String password;

    private void encryptPassword() {
        System.out.println("Шифруем пароль");
    }
}
```

Используется, чтобы скрыть внутренние данные и реализацию.

Обычно поля делают `private`:

```java
public class User {
    private String name;

    public String getName() {
        return name;
    }

    public void setName(String userName) {
        name = userName;
    }
}
```

---

### 15.4. protected

`protected` — доступен:

* внутри текущего класса;
* внутри классов того же пакета;
* в дочерних классах.

```java
public class Animal {
    protected String name;
}
```

```java
public class Cat extends Animal {
    public void printName() {
        System.out.println(name);
    }
}
```

Используется при наследовании, когда нужно дать доступ дочерним классам.

---

### 15.5. default access

Если модификатор не указан, это **default** или **package-private** доступ.

```java
class User {
    String name;
}
```

Доступ будет только внутри того же пакета.

Используется, когда класс или метод нужен только внутри одного пакета.

---

### 15.6. Таблица модификаторов доступа

| Модификатор | Внутри класса | Внутри пакета |           В наследнике | Откуда угодно |
| ----------- | ------------: | ------------: | ---------------------: | ------------: |
| `private`   |            Да |           Нет |                    Нет |           Нет |
| default     |            Да |            Да | Нет, если другой пакет |           Нет |
| `protected` |            Да |            Да |                     Да |           Нет |
| `public`    |            Да |            Да |                     Да |            Да |

---

### 15.7. Что такое пакет

**Пакет** — это способ группировать классы по смыслу.

Пример объявления пакета:

```java
package ru.company.project.users;
```

Пакет указывается в самом начале файла.

---

### 15.8. Зачем нужны пакеты

Пакеты нужны, чтобы:

* структурировать проект;
* разделять код по смыслу;
* избегать конфликтов имён;
* проще находить нужные классы;
* управлять доступом через package-private.

Пример структуры:

```text
src/main/java
└── ru
    └── company
        └── project
            ├── users
            │   └── User.java
            ├── orders
            │   └── Order.java
            └── payments
                └── PaymentService.java
```

---

### 15.9. Импорты

Если нужно использовать класс из другого пакета, его импортируют.

```java
import java.util.ArrayList;
import java.util.List;
```

Пример:

```java
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<String> names = new ArrayList<>();
    }
}
```

---

### 15.10. Когда какие модификаторы использовать

| Ситуация                             | Что использовать |
| ------------------------------------ | ---------------- |
| Поля класса                          | чаще `private`   |
| Методы для внешнего использования    | `public`         |
| Вспомогательные методы внутри класса | `private`        |
| Методы для наследников               | `protected`      |
| Класс нужен только внутри пакета     | default          |
| DTO, service, controller, test class | часто `public`   |
