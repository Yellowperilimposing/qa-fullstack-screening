## 3. Операторы и выражения

> [!abstract] Коротко
> Оператор — это символ или конструкция, которая выполняет действие.


### 3.1. Что такое оператор?

**Оператор** — это символ или конструкция, которая выполняет действие.

Например:

```java
int result = 10 + 5;
```

Здесь `+` — оператор сложения.

---

### 3.2. Арифметические операторы

| Оператор | Значение           | Пример   | Результат |
| -------- | ------------------ | -------- | --------- |
| `+`      | сложение           | `10 + 5` | `15`      |
| `-`      | вычитание          | `10 - 5` | `5`       |
| `*`      | умножение          | `10 * 5` | `50`      |
| `/`      | деление            | `10 / 5` | `2`       |
| `%`      | остаток от деления | `10 % 3` | `1`       |

Пример:

```java
int a = 10;
int b = 3;

System.out.println(a + b); // 13
System.out.println(a - b); // 7
System.out.println(a * b); // 30
System.out.println(a / b); // 3
System.out.println(a % b); // 1
```

Важно: если делить `int` на `int`, результат тоже будет `int`.

```java
int result = 10 / 3;
System.out.println(result); // 3
```

Чтобы получить дробный результат:

```java
double result = 10.0 / 3;
System.out.println(result); // 3.3333333333333335
```

---

### 3.3. Операторы сравнения

Операторы сравнения возвращают `true` или `false`.

| Оператор | Значение         | Пример   |
| -------- | ---------------- | -------- |
| `==`     | равно            | `a == b` |
| `!=`     | не равно         | `a != b` |
| `>`      | больше           | `a > b`  |
| `<`      | меньше           | `a < b`  |
| `>=`     | больше или равно | `a >= b` |
| `<=`     | меньше или равно | `a <= b` |

Пример:

```java
int age = 18;

System.out.println(age == 18); // true
System.out.println(age > 21);  // false
```

---

### 3.4. Логические операторы

Логические операторы используются для объединения условий.

| Оператор | Название | Значение                        |     |                                       |
| -------- | -------- | ------------------------------- | --- | ------------------------------------- |
| `&&`     | И        | оба условия должны быть true    |     |                                       |
| `        |          | `                               | ИЛИ | хотя бы одно условие должно быть true |
| `!`      | НЕ       | меняет true на false и наоборот |     |                                       |

Пример:

```java
int age = 25;
boolean hasPassport = true;

boolean canTravel = age >= 18 && hasPassport;

System.out.println(canTravel); // true
```

Пример с `||`:

```java
boolean isAdmin = false;
boolean isManager = true;

boolean hasAccess = isAdmin || isManager;

System.out.println(hasAccess); // true
```

Пример с `!`:

```java
boolean isBlocked = false;

System.out.println(!isBlocked); // true
```

---

### 3.5. Тернарный оператор

**Тернарный оператор** — это короткая форма `if-else`.

Синтаксис:

```java
условие ? значение_если_true : значение_если_false;
```

Пример:

```java
int age = 20;

String result = age >= 18 ? "Взрослый" : "Несовершеннолетний";

System.out.println(result); // Взрослый
```

То же самое через `if-else`:

```java
String result;

if (age >= 18) {
    result = "Взрослый";
} else {
    result = "Несовершеннолетний";
}
```

Тернарный оператор удобен, когда условие простое.
