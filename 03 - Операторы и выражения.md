## 3. Операторы и выражения

> [!abstract] Коротко
> Операторы выполняют действия над значениями: арифметику, сравнение, логические проверки, присваивание и преобразование результата.

### 3.1. Арифметические операторы

| Оператор | Значение |
| --- | --- |
| `+` | сложение; для строк — конкатенация |
| `-` | вычитание |
| `*` | умножение |
| `/` | деление |
| `%` | остаток от деления |

```java
int a = 10;
int b = 3;

System.out.println(a / b); // 3
System.out.println(a % b); // 1
```

Если оба операнда целочисленные, дробная часть результата отбрасывается. Для дробного результата хотя бы один операнд должен быть `float`/`double`:

```java
double result = 10.0 / 3; // 3.333...
```

---

### 3.2. Инкремент и декремент

```java
int x = 5;
x++; // 6
x--; // 5
```

Префиксная и постфиксная формы отличаются моментом получения значения:

```java
int a = 5;
int b = a++; // b = 5, a = 6

int c = 5;
int d = ++c; // c = 6, d = 6
```

---

### 3.3. Сравнение

| Оператор | Значение |
| --- | --- |
| `==` | равно |
| `!=` | не равно |
| `>` | больше |
| `<` | меньше |
| `>=` | больше или равно |
| `<=` | меньше или равно |

Для примитивов `==` сравнивает значения. Для ссылочных типов `==` проверяет, указывают ли ссылки на один и тот же объект. Содержимое объектов обычно сравнивают через `equals()`.

---

### 3.4. Логические операторы

| Оператор | Значение |
| --- | --- |
| `&&` | логическое И |
| `||` | логическое ИЛИ |
| `!` | логическое НЕ |

```java
boolean canTravel = age >= 18 && hasPassport;
boolean hasAccess = isAdmin || isManager;
boolean allowed = !isBlocked;
```

`&&` и `||` используют short-circuit evaluation: правая часть может не вычисляться, если результат уже понятен по левой.

```java
if (user != null && user.isActive()) {
    // второй вызов выполнится только если user != null
}
```

---

### 3.5. Побитовые операторы

Для целочисленных типов существуют `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`.

`&` и `|` также могут применяться к `boolean`, но, в отличие от `&&` и `||`, обе стороны выражения вычисляются всегда.

---

### 3.6. Операторы присваивания

```java
int x = 10;
x += 5; // x = x + 5
x -= 2;
x *= 3;
x /= 2;
x %= 4;
```

---

### 3.7. Тернарный оператор

Тернарный оператор `?:` возвращает одно из двух значений:

```java
String result = age >= 18 ? "Взрослый" : "Несовершеннолетний";
```

Он удобен для простых выражений. Сложную ветвящуюся логику лучше оставлять в `if/else` или `switch`.

---

### 3.8. Приоритет операций

У операторов есть приоритет. Если порядок неочевиден, лучше использовать скобки:

```java
int result = (a + b) * c;
```

Так код легче читать и сложнее неверно интерпретировать.
