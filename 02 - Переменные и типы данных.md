## 2. Переменные и типы данных

> [!abstract] Коротко
> Переменная — это именованное место в памяти, где хранится значение.


### 2.1. Что такое переменная?

**Переменная** — это именованное место в памяти, где хранится значение.

Пример:

```java
int age = 28;
```

Здесь:

* `int` — тип данных;
* `age` — имя переменной;
* `28` — значение.

Можно представить переменную как коробку:

```text
age → [28]
```

---

### 2.2. Примитивные типы данных

**Примитивные типы** — это базовые типы, которые хранят значение напрямую.

| Тип | Размер | Значения / диапазон | Где встречается |
| --- | --- | --- | --- |
| `boolean` | 1 бит | `true` / `false` | Проверка состояния элемента: `isDisplayed()` |
| `byte` | 1 байт | от `-128` до `127` | Редко, но может быть в API-ответах |
| `short` | 2 байта | от `-32768` до `32767` | Редко |
| `int` | 4 байта | примерно от `-2 млрд` до `2 млрд` | Счетчики, ID, номера страниц |
| `long` | 8 байт | очень большие числа | Временные метки, ID в БД |
| `float` | 4 байта | дробные числа, меньшая точность | Цены, координаты, редко |
| `double` | 8 байт | дробные числа, большая точность | Цены, расчеты, API-ответы |
| `char` | 2 байта | один символ Unicode | Ввод символа в поле |

Примеры:

```java
int count = 10;
double price = 99.99;
boolean isDisplayed = true;
char symbol = 'A';
long userId = 100000L;
```

---

### 2.3. Ссылочные типы данных

**Ссылочные типы** — это объекты. Они хранятся в куче, а в переменной хранится только ссылка на объект.

| Тип | Что это |
| --- | --- |
| `String` | Строка. Не примитив, хотя выглядит как простой тип |
| `Integer`, `Double` | Обертки примитивов, например `Integer i = 10;` |
| `List<String>`, `Map<String, Object>` | Коллекции |
| `WebDriver`, `SelenideElement`, `Response` | Объекты из фреймворков |
| Массивы | Объекты, даже если хранят примитивы: `int[] numbers` |
| Пользовательские классы | Например `User`, `LoginPage`, `Order` |

Примеры:

```java
String name = "Danil";
Integer age = 28;
List<String> names = List.of("Danil", "Anna");
WebDriver driver = new ChromeDriver();
User user = new User();
```

`String` — это не примитив, а класс.

Переменная `user` хранит ссылку на объект класса `User`.

---

### 2.4. Отличие примитивных и ссылочных типов

| Примитивные типы          | Ссылочные типы                 |
| ------------------------- | ------------------------------ |
| Хранят простое значение   | Хранят ссылку на объект        |
| Пишутся с маленькой буквы | Обычно пишутся с большой буквы |
| Не могут быть `null`      | Могут быть `null`              |
| Пример: `int`, `boolean`  | Пример: `String`, `User`       |

Пример:

```java
int age = 28;
String name = "Danil";
```

`age` хранит число.

`name` хранит ссылку на строковый объект.

---

### 2.5. Что такое null

`null` — это специальное значение для ссылочных типов.

Оно означает, что переменная не ссылается ни на какой объект.

```java
String name = null;
```

Здесь переменная `name` есть, но объекта строки нет.

Если вызвать метод у `null`, будет `NullPointerException`.

```java
String name = null;

System.out.println(name.length()); // NullPointerException
```

`null` может быть только у ссылочных типов:

```java
String text = null; // можно
User user = null;   // можно
```

У примитивов `null` быть не может:

```java
int age = null; // ошибка компиляции
```

---

### 2.6. Правила именования переменных

Имена переменных должны быть понятными.

Хорошо:

```java
int userAge = 28;
String userName = "Danil";
boolean isActive = true;
```

Плохо:

```java
int a = 28;
String x = "Danil";
boolean b = true;
```

Основные правила:

* имя может содержать буквы, цифры, `_`, `$`;
* имя не может начинаться с цифры;
* нельзя использовать ключевые слова Java;
* принято писать в стиле `camelCase`.

Пример `camelCase`:

```java
int userAge;
String accountNumber;
boolean isUserBlocked;
```

---

### 2.7. Константы

**Константа** — это переменная, значение которой нельзя изменить после присваивания.

В Java для этого используется ключевое слово `final`.

Пример:

```java
final int MAX_USERS = 100;
```

Попытка изменить значение вызовет ошибку:

```java
MAX_USERS = 200; // ошибка
```

Обычно константы пишут большими буквами:

```java
final double PI = 3.14;
final String APP_NAME = "Test App";
```
