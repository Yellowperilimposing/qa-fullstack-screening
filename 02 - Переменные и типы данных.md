## 2. Переменные и типы данных

> [!abstract] Коротко
> Java — строго типизированный язык: у каждой переменной есть тип, который определяет допустимые значения и операции.

### 2.1. Переменная

```java
int age = 28;
```

Здесь `int` — тип, `age` — имя переменной, `28` — значение.

Локальную переменную нужно инициализировать до чтения. Поля класса получают значения по умолчанию автоматически.

---

### 2.2. Примитивные типы

В Java восемь примитивных типов:

| Тип | Размер | Диапазон / значение |
| --- | ---: | --- |
| `byte` | 8 бит | `-128 .. 127` |
| `short` | 16 бит | `-32768 .. 32767` |
| `int` | 32 бита | `-2^31 .. 2^31-1` |
| `long` | 64 бита | `-2^63 .. 2^63-1` |
| `float` | 32 бита | число с плавающей точкой одинарной точности |
| `double` | 64 бита | число с плавающей точкой двойной точности |
| `char` | 16 бит | одна кодовая единица UTF-16 (`0 .. 65535`) |
| `boolean` | JVM-зависимо | только `true` или `false` |

Важно: спецификация Java не задаёт для `boolean` фиксированный размер хранения вроде «1 бит».

```java
int count = 10;
long id = 10_000_000_000L;
double ratio = 0.75;
char letter = 'A';
boolean active = true;
```

`char` не всегда соответствует одному видимому Unicode-символу: некоторые символы представлены парой UTF-16 code units.

Для денег обычно не используют `float`/`double`, если нужна точная десятичная арифметика. В таких случаях применяют `BigDecimal`.

---

### 2.3. Литералы и числовые типы

Целочисленный литерал без суффикса обычно имеет тип `int`. Для `long` используют `L`:

```java
long value = 3_000_000_000L;
```

Литерал с десятичной точкой по умолчанию имеет тип `double`. Для `float` нужен `F`:

```java
float rate = 1.5F;
double price = 1.5;
```

---

### 2.4. Ссылочные типы

Ссылочные переменные содержат ссылку на объект. К ссылочным типам относятся классы, интерфейсы, массивы, enum и другие объектные типы.

```java
String name = "Danil";
Integer age = 28;
int[] numbers = {1, 2, 3};
User user = new User();
```

`String` и классы-обёртки (`Integer`, `Long`, `Double` и т.д.) — не примитивы.

---

### 2.5. `null`

`null` означает отсутствие ссылки на объект и допустим только для ссылочных типов:

```java
String text = null;
User user = null;
```

```java
int age = null; // ошибка компиляции
```

Вызов метода через `null` обычно приводит к `NullPointerException`.

---

### 2.6. Примитивы и обёртки

Для примитивов существуют классы-обёртки:

| Примитив | Обёртка |
| --- | --- |
| `int` | `Integer` |
| `long` | `Long` |
| `double` | `Double` |
| `boolean` | `Boolean` |
| `char` | `Character` |

Java умеет автоматически преобразовывать примитив в обёртку и обратно — autoboxing/unboxing:

```java
Integer boxed = 10; // autoboxing
int value = boxed;  // unboxing
```

Если выполнить unboxing у `null`, возникнет `NullPointerException`.

---

### 2.7. `final`

`final` запрещает повторно присвоить переменной другое значение:

```java
final int MAX_USERS = 100;
```

Для ссылочной переменной `final` запрещает изменить саму ссылку, но не обязательно состояние объекта:

```java
final List<String> names = new ArrayList<>();
names.add("Danil"); // допустимо
// names = new ArrayList<>(); // нельзя
```

Константы уровня класса обычно объявляют как `static final` и называют в `UPPER_SNAKE_CASE`.

---

### 2.8. Именование

Идентификатор может содержать буквы, цифры, `_`, `$`, но не может начинаться с цифры и совпадать с ключевым словом Java. Для переменных принято использовать `camelCase`.

```java
int userAge;
String accountNumber;
boolean isActive;
```
