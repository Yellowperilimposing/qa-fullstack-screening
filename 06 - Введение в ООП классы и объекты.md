## 6. Введение в ООП: классы и объекты

> [!abstract] Коротко
> ООП — объектно-ориентированное программирование.


### 6.1. Что такое ООП?

**ООП** — объектно-ориентированное программирование.

Главная идея: программа строится из объектов.

Объект — это сущность, у которой есть:

* состояние;
* поведение.

Например, объект `User`.

Состояние:

* имя;
* возраст;
* email.

Поведение:

* авторизоваться;
* изменить пароль;
* отправить сообщение.

---

### 6.2. Что такое класс?

**Класс** — это шаблон для создания объектов.

Пример класса:

```java
public class User {
    String name;
    int age;
}
```

Класс `User` описывает, что у пользователя есть:

* `name`;
* `age`.

---

### 6.3. Что такое объект?

**Объект** — это конкретный экземпляр класса.

Если класс — это чертёж, то объект — это вещь, созданная по этому чертежу.

Пример:

```java
User user = new User();
```

Здесь создаётся объект класса `User`.

---

### 6.4. Поля класса

**Поля** — это переменные внутри класса.

Они описывают состояние объекта.

```java
public class User {
    String name;
    int age;
}
```

Здесь:

```java
String name;
int age;
```

это поля класса `User`.

---

### 6.5. Методы класса

**Методы** описывают поведение объекта.

```java
public class User {
    String name;
    int age;

    void sayHello() {
        System.out.println("Привет, меня зовут " + name);
    }
}
```

Метод:

```java
void sayHello()
```

выводит приветствие.

---

### 6.6. Создание объекта

```java
public class Main {
    public static void main(String[] args) {
        User user = new User();

        user.name = "Danil";
        user.age = 28;

        user.sayHello();
    }
}
```

Результат:

```text
Привет, меня зовут Danil
```

---

### 6.7. Конструкторы

**Конструктор** — это специальный метод, который вызывается при создании объекта.

Он нужен, чтобы сразу задать начальные значения полей.

Пример:

```java
public class User {
    String name;
    int age;

    public User(String userName, int userAge) {
        name = userName;
        age = userAge;
    }
}
```

Создание объекта:

```java
User user = new User("Danil", 28);
```

Теперь поля сразу заполнены:

```java
System.out.println(user.name); // Danil
System.out.println(user.age);  // 28
```

---

### 6.8. Конструктор по умолчанию

Если в классе не написать конструктор, Java создаст пустой конструктор сама.

```java
public class User {
    String name;
    int age;
}
```

Можно создать объект так:

```java
User user = new User();
```

Но если ты сам написал конструктор с параметрами, пустой конструктор автоматически уже не создаётся.
