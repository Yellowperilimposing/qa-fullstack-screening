## 5. Циклы

> [!abstract] Коротко
> Цикл нужен, чтобы повторять один и тот же код несколько раз.


### 5.1. Что такое цикл?

**Цикл** нужен, чтобы повторять один и тот же код несколько раз.

Например, вместо такого кода:

```java
System.out.println("Привет");
System.out.println("Привет");
System.out.println("Привет");
```

можно написать:

```java
for (int i = 0; i < 3; i++) {
    System.out.println("Привет");
}
```

---

### 5.2. Цикл for

`for` используется, когда заранее известно, сколько раз нужно повторить действие.

Синтаксис:

```java
for (начало; условие; шаг) {
    // код
}
```

Пример:

```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

Результат:

```text
1
2
3
4
5
```

Разбор:

```java
int i = 1
```

Начальное значение счётчика.

```java
i <= 5
```

Цикл работает, пока условие истинно.

```java
i++
```

После каждой итерации `i` увеличивается на 1.

---

### 5.3. Цикл for-each

`for-each` используется, когда нужно пройти по всем элементам массива или коллекции.

Он удобен, если не нужен индекс элемента.

Синтаксис:

```java
for (тип переменная : коллекция) {
    // код
}
```

Пример с массивом:

```java
int[] numbers = {1, 2, 3};

for (int number : numbers) {
    System.out.println(number);
}
```

Результат:

```text
1
2
3
```

Пример с коллекцией:

```java
List<String> names = List.of("Danil", "Anna", "Ivan");

for (String name : names) {
    System.out.println(name);
}
```

Когда использовать `for-each`:

* нужно пройти по всем элементам;
* не нужен индекс;
* не нужно менять структуру коллекции во время обхода.

Если нужен индекс, лучше использовать обычный `for`.

---

### 5.4. Цикл while

`while` используется, когда количество повторений заранее может быть неизвестно.

Синтаксис:

```java
while (условие) {
    // код
}
```

Пример:

```java
int count = 1;

while (count <= 5) {
    System.out.println(count);
    count++;
}
```

Результат:

```text
1
2
3
4
5
```

Важно: если условие всегда `true`, получится бесконечный цикл.

```java
while (true) {
    System.out.println("Бесконечный цикл");
}
```

---

### 5.5. Цикл do-while

`do-while` похож на `while`, но сначала выполняет код, а потом проверяет условие.

Синтаксис:

```java
do {
    // код
} while (условие);
```

Пример:

```java
int number = 1;

do {
    System.out.println(number);
    number++;
} while (number <= 5);
```

Главная особенность: `do-while` выполнится минимум один раз.

Пример:

```java
int number = 10;

do {
    System.out.println(number);
} while (number < 5);
```

Результат:

```text
10
```

Хотя условие `number < 5` ложное, тело цикла выполнилось один раз.

---

### 5.6. break

`break` полностью останавливает цикл.

Пример:

```java
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;
    }

    System.out.println(i);
}
```

Результат:

```text
1
2
3
4
```

Когда `i` стало равно `5`, цикл остановился.

---

### 5.7. continue

`continue` пропускает текущую итерацию и переходит к следующей.

Пример:

```java
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }

    System.out.println(i);
}
```

Результат:

```text
1
2
4
5
```

Когда `i` равно `3`, `System.out.println(i)` не выполнился.
