## Как пользоваться

Для последовательной подготовки начинай с [индекса](00%20-%20Индекс.md) и проходи заметки по порядку.

Если до скрининга осталось мало времени:

1. Повтори `33 - Блок вопросов для скрининга`.
2. Пройдись по `34 - Короткая памятка по синтаксису`.
3. Используй `35 - Ответы на вопросы для собеседования` для повторения формулировок ответов.
4. Точечно возвращайся к Java Core, JUnit, Selenide, Rest Assured, БД, Git и CI/CD.

## Формат материалов

Заметки написаны в Markdown и содержат:

- краткое объяснение темы;
- примеры Java-кода;
- таблицы и сравнения;
- типовые сценарии из автотестов;
- формулировки, которые удобно использовать на техническом скрининге;
- внутренние Obsidian wikilinks для навигации между заметками.

## Быстрый старт локально

```bash
git clone https://github.com/Yellowperilimposing/qa-fullstack-screening.git
cd qa-fullstack-screening
```

Репозиторий можно читать прямо на GitHub или открыть как папку/vault в Obsidian.
