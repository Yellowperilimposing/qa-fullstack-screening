## 8. Исключения

> [!abstract] Коротко
> Исключение — это ошибка, которая возникает во время выполнения программы.


### 8.1. Что такое исключение?

**Исключение** — это ошибка, которая возникает во время выполнения программы.

Например:

```java
int result = 10 / 0;
```

Будет ошибка:

```text
ArithmeticException
```

Потому что на ноль делить нельзя.

---

### 8.2. Зачем нужны исключения?

Исключения нужны, чтобы программа могла:

* сообщить об ошибке;
* не упасть неожиданно;
* обработать проблемную ситуацию;
* продолжить работу, если это возможно.

Пример жизненной ситуации:

```text
Пользователь ввёл неправильный пароль.
Файл не найден.
Сервер не ответил.
В массиве нет элемента с таким индексом.
```

---

### 8.3. Примеры частых исключений

| Исключение                       | Когда возникает                                 |
| -------------------------------- | ----------------------------------------------- |
| `NullPointerException`           | обращение к объекту, который равен `null`       |
| `ArrayIndexOutOfBoundsException` | обращение к несуществующему индексу массива     |
| `ArithmeticException`            | математическая ошибка, например деление на ноль |
| `NumberFormatException`          | ошибка преобразования строки в число            |
| `FileNotFoundException`          | файл не найден                                  |

---

### 8.4. NullPointerException

Одна из самых частых ошибок в Java.

Пример:

```java
String name = null;

System.out.println(name.length()); // NullPointerException
```

Почему ошибка?

Потому что `name` не ссылается на объект. Там `null`.

Правильнее сначала проверить:

```java
String name = null;

if (name != null) {
    System.out.println(name.length());
} else {
    System.out.println("Имя отсутствует");
}
```

---

### 8.5. try-catch

`try-catch` используется для обработки исключений.

Синтаксис:

```java
try {
    // код, где может быть ошибка
} catch (Exception e) {
    // что делать, если ошибка произошла
}
```

Пример:

```java
try {
    int result = 10 / 0;
    System.out.println(result);
} catch (ArithmeticException e) {
    System.out.println("Ошибка: деление на ноль");
}
```

Результат:

```text
Ошибка: деление на ноль
```

Программа не упала, потому что мы обработали ошибку.

---

### 8.6. finally

Блок `finally` выполняется всегда:

* если ошибки не было;
* если ошибка была;
* если ошибка была обработана.

Пример:

```java
try {
    int result = 10 / 2;
    System.out.println(result);
} catch (ArithmeticException e) {
    System.out.println("Ошибка");
} finally {
    System.out.println("Блок finally выполнен");
}
```

Результат:

```text
5
Блок finally выполнен
```

`finally` часто используют, чтобы закрыть ресурсы: файл, соединение с базой данных, сетевое подключение.

---

### 8.7. throw

`throw` используется, чтобы вручную выбросить исключение.

Пример:

```java
public void checkAge(int age) {
    if (age < 18) {
        throw new IllegalArgumentException("Возраст должен быть 18 или больше");
    }

    System.out.println("Возраст подходит");
}
```

Если передать возраст меньше 18, программа выбросит исключение.

---

### 8.8. throws

`throws` указывается в объявлении метода и говорит, что метод может выбросить исключение.

Пример:

```java
public void readFile() throws Exception {
    // код чтения файла
}
```

То есть метод предупреждает:
«Я могу выбросить исключение, обработай меня снаружи».

---

### 8.9. Checked и unchecked exceptions

В Java исключения делятся на два основных типа.

#### Checked exceptions

Это исключения, которые Java заставляет обработать.

Пример:

```java
FileNotFoundException
IOException
```

Если метод может выбросить checked exception, нужно:

или обработать через `try-catch`:

```java
try {
    // работа с файлом
} catch (Exception e) {
    System.out.println("Ошибка при работе с файлом");
}
```

или указать `throws`:

```java
public void readFile() throws Exception {
    // работа с файлом
}
```

---

#### Unchecked exceptions

Это исключения, которые Java не заставляет обрабатывать.

Они обычно связаны с ошибками в логике программы.

Примеры:

```java
NullPointerException
ArithmeticException
ArrayIndexOutOfBoundsException
IllegalArgumentException
```
