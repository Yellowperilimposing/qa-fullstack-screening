## 12. Наследование

> [!abstract] Коротко
> Наследование — это механизм, при котором один класс расширяет другой класс.


### 12.1. Что такое наследование

**Наследование** — это механизм, при котором один класс расширяет другой класс.

Используется ключевое слово `extends`.

```java
public class Cat extends Animal {
}
```

Это значит: `Cat` наследуется от `Animal`.

---

### 12.2. Пример наследования

```java
public class Animal {
    String name;

    public void eat() {
        System.out.println("Животное ест");
    }
}
```

```java
public class Cat extends Animal {
    public void meow() {
        System.out.println("Кот мяукает");
    }
}
```

Использование:

```java
Cat cat = new Cat();

cat.name = "Barsik";
cat.eat();
cat.meow();
```

Класс `Cat` получил поле `name` и метод `eat()` от класса `Animal`.

---

### 12.3. Переопределение методов

**Переопределение метода** — это когда дочерний класс изменяет поведение метода родительского класса.

Используется аннотация `@Override`.

```java
public class Animal {
    public void makeSound() {
        System.out.println("Животное издаёт звук");
    }
}
```

```java
public class Cat extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Мяу");
    }
}
```

Использование:

```java
Cat cat = new Cat();

cat.makeSound(); // Мяу
```

---

### 12.4. super

`super` используется для обращения к родительскому классу.

Пример вызова метода родителя:

```java
public class Animal {
    public void makeSound() {
        System.out.println("Животное издаёт звук");
    }
}
```

```java
public class Cat extends Animal {
    @Override
    public void makeSound() {
        super.makeSound();
        System.out.println("Мяу");
    }
}
```

Результат:

```text
Животное издаёт звук
Мяу
```

---

### 12.5. Наследование и конструкторы

Конструктор родительского класса можно вызвать через `super()`.

```java
public class Animal {
    String name;

    public Animal(String animalName) {
        name = animalName;
    }
}
```

```java
public class Cat extends Animal {
    public Cat(String catName) {
        super(catName);
    }
}
```

---

### 12.6. Важные правила наследования

1. В Java класс может наследоваться только от одного класса.
2. Один класс может реализовать много интерфейсов.
3. `private` поля и методы не доступны напрямую в дочернем классе.
4. Конструкторы не наследуются.
5. Через `super` можно обратиться к родительскому классу.
