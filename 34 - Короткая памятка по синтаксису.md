### 34.12. Коллекции и объект целиком

```java
// Массив
int[] numbers = {1, 2, 3};

// Список
List<String> names = new ArrayList<>();

// Множество
Set<String> uniqueNames = new HashSet<>();

// Ключ-значение
Map<String, Integer> ages = new HashMap<>();

// Класс
public class User {
    private String name;

    public User(String userName) {
        name = userName;
    }

    public String getName() {
        return name;
    }
}

// Объект
User user = new User("Danil");

// Вызов метода
System.out.println(user.getName());
```
