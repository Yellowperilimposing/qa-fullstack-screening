## 34. Короткая памятка по синтаксису

> [!abstract] Коротко
> Минимальный синтаксис Java, который полезно быстро вспомнить перед скринингом.

### 34.1. Переменная и константа

```java
int age = 28;
final int MAX_COUNT = 100;
```

---

### 34.2. `if-else`

```java
if (age >= 18) {
    System.out.println("Можно");
} else {
    System.out.println("Нельзя");
}
```

---

### 34.3. Современный `switch`

```java
switch (status) {
    case "ACTIVE" -> System.out.println("Активен");
    case "BLOCKED" -> System.out.println("Заблокирован");
    default -> System.out.println("Неизвестный статус");
}
```

`switch` как выражение:

```java
String label = switch (status) {
    case "ACTIVE" -> "Активен";
    case "BLOCKED" -> "Заблокирован";
    default -> "Неизвестен";
};
```

Классическая форма `case ...: ... break;` тоже поддерживается.


### 34.6. Класс, конструктор и объект

```java
public class User {
    private String name;

    public User(String name) {
        this.name = name;
    }

    public String getName() {
        return name;
    }
}

User user = new User("Danil");
```

### 34.8. Исключения


### 34.10. Stream API


### 34.11. Сравнение строк

```java
"ACTIVE".equals(status); // сравнение содержимого, null-safe для status
```

Для ссылок `==` проверяет идентичность объектов, а не текстовое содержимое.
